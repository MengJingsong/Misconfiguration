Trees from `copy-source.sh`: `~/s4-b8-ls-u` (`ant build-test`, unit tier) and `~/s4-b8-ls-n` (`ant jar`, node). Needs `sudo` for tmpfs mounts. Run the unit script and the cluster script one after the other, never together (the unit script's cleanup unmounts everything under `~/s4-b8-ls-mnt`).
