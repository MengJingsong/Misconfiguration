## A. Constraint trace

**A1. The constraint.** The target (GuardrailsOptions.java:1219, inside the private static helper `validateWarnLowerThanFail(LongBytesBound warn, LongBytesBound fail, String name)`, 1214-1222) is not itself a memory/disk cap; it is a config-consistency check that rejects a fail threshold below its warn threshold (`fail.toBytes() < warn.toBytes()`, with null on either side skipping the check, 1216-1217). It is reached via `validateSizeThreshold` (1207-1212) from the startup validation at GuardrailsOptions.java:79 (partition_size), 81 (column_value_size), 82 (collection_size) and from the runtime setters at 565 (partition_size), 617 (column_value_size), 644 (collection_size), 980/1008/1036 (sai_string/frozen/vector_term_size). The values compared are the paired guardrail size thresholds, kind: configuration entries, `*_warn_threshold` / `*_fail_threshold`, first declared in Config.java as `DataStorageSpec.LongBytesBound` fields: partition_size at Config.java:910-911, column_value_size at 915-916, collection_size at 917-918, and sai_string_term_size / sai_frozen_term_size / sai_vector_term_size at 941-946. Unit: bytes (LongBytesBound, e.g. "1KiB"; converted by `toBytes()`). Defaults: null (disabled) for partition_size, column_value_size and collection_size (Config.java:910-918, hard-coded, not derived); hard-coded 1KiB/8KiB for sai_string and sai_frozen terms and 16KiB/32KiB for sai_vector terms (Config.java:941-946); partition_size also accepts the deprecated compaction_large_partition_warning_threshold names via @Replaces (Config.java:908-909). Settable via cassandra.yaml keys of those names (read into Config and validated at startup, GuardrailsOptions.java:79-82) and at runtime via JMX through Guardrails (e.g. `setPartitionSizeThreshold`, Guardrails.java:924-926, which calls GuardrailsOptions.java:563-565); a JMX change takes effect without restart, a yaml change needs a restart. The guardrails these thresholds feed (e.g. Guardrails.partitionSize, Guardrails.java:332-336) warn or fail on data sizes, but the check at 1219 only enforces warn <= fail ordering and has no memory/disk limit of its own.
