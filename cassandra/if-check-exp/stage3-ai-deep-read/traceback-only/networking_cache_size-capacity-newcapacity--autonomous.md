## A. Constraint trace

**A1. The constraint.** `networking_cache_size` is a configuration entry that caps the memory of the "networking" BufferPool, which backs `BufferPoolAllocator` (`BufferPoolAllocator.java:40`, `bufferPool = BufferPools.forNetworking()`). The target line (`BufferPoolAllocator.java:121`, `if (newCapacity == capacity()) return this;` in `Wrapped.capacity`) is only a no-op shortcut. It checks nothing itself, but a resize that gets past it reallocates through `bufferPool.getAtLeast` (`BufferPoolAllocator.java:136`) and `bufferPool.put` (`BufferPoolAllocator.java:128`), and that pool enforces the cap. The field is first declared at `Config.java:493-494` as `public DataStorageSpec.IntMebibytesBound networking_cache_size`, replacing the old `networking_cache_size_in_mb`. `DatabaseDescriptor.getNetworkingCacheSizeInMiB()` (`DatabaseDescriptor.java:3796-3804`) returns it, and returns 0 in client mode. `BufferPools.java:44` turns it into bytes (`* 1024L * 1024L`, `NETWORKING_MEMORY_USAGE_THRESHOLD`) and passes it as `memoryUsageThreshold` to `new BufferPool("networking", ..., false)` (`BufferPools.java:45`; stored at `BufferPool.java:190`). The cap is enforced in `BufferPool.allocateMoreChunks`: `if (cur + MACRO_CHUNK_SIZE > memoryUsageThreshold)` (`BufferPool.java:443`) returns null and logs "Maximum memory usage reached" (`BufferPool.java:445-448`). `MACRO_CHUNK_SIZE` is 64 * `NORMAL_CHUNK_SIZE`, and `NORMAL_CHUNK_SIZE` is 128 KiB (`BufferPool.java:385,128`), so the macro chunk is 8 MiB. The unit is MiB (`IntMebibytesBound`; `conf/cassandra.yaml:737` says "Min unit: MiB"). The default is derived in `DatabaseDescriptor.java:573-574` when unset: `min(128, maxMemory / (16 * 1048576))` MiB. That is 1/16 of the JVM max heap, capped at 128 MiB, matching the commented-out `# networking_cache_size: 128MiB` at `conf/cassandra.yaml:738`. It is set through the yaml key `networking_cache_size` (or the deprecated `networking_cache_size_in_mb`) and needs a restart: the value is read into static finals when `BufferPools` loads (`BufferPools.java:44-45`). I found no JMX setter in `src/java`.
