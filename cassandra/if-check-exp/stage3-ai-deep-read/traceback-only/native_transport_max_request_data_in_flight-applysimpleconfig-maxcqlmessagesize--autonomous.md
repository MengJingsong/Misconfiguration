## A. Constraint trace

**A1. The constraint.** `native_transport_max_request_data_in_flight` is a configuration entry (cassandra.yaml key) capping the total bytes of in-flight native-transport (CQL) request data, which is held in memory, across all client connections. It is first declared at `src/java/org/apache/cassandra/config/Config.java:298` as `public volatile DataStorageSpec.LongBytesBound ... = null`, with `@Replaces(oldName = "native_transport_max_concurrent_requests_in_bytes", converter = Converters.BYTES_CUSTOM_DATASTORAGE, deprecated = true)` at `Config.java:297`. The unit is bytes, expressed as a data-storage spec (for example `100MiB`). The default is null in Config; `DatabaseDescriptor.java:649-652` sets it to `Runtime.getRuntime().maxMemory() / 10`, which is 10% of the JVM max heap. The check at `DatabaseDescriptor.java:910-912` compares `maxCqlMessageSize`, the value of `native_transport_max_message_size` in bytes (`DatabaseDescriptor.java:910`), against this limit. It throws a ConfigurationException if the message size exceeds it. It runs only when `native_transport_max_message_size` is set explicitly (`DatabaseDescriptor.java:907-909`). A companion check at `DatabaseDescriptor.java:914` does the same against the per-IP limit `native_transport_max_request_data_in_flight_per_ip`, which defaults to maxMemory/40 (`DatabaseDescriptor.java:654-657`). The value is set through the yaml key (or the deprecated old name) at startup, which needs a restart. It can also be changed at runtime, because the field is volatile and `DatabaseDescriptor.setNativeTransportConcurrentRequestDataInFlightInBytes` (`DatabaseDescriptor.java:3385-3389`) is wired to `ClientResourceLimits` (`transport/ClientResourceLimits.java:64-69`). In that setter, -1 resets it to maxMemory/10 (`DatabaseDescriptor.java:3387-3388`). The runtime setter does not re-run the startup check against `native_transport_max_message_size`. It clamps the message size with Math.min when that was configured explicitly (`DatabaseDescriptor.java:3390-3392`).
