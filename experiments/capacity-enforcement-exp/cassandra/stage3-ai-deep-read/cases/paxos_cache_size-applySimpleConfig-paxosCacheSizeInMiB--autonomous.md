## A. Constraint trace

The constraint.** `paxos_cache_size`, configuration entry ([`Config.java:485`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/config/Config.java#L485), `LongMebibytesBound`, default `null` = auto; not present in `conf/cassandra.yaml`). Negative → `ConfigurationException` (`:854-861`), unreachable (`DataStorageSpec.java:42,72,107-108`). Getter `getPaxosCacheSizeInMiB()` (`:3942-3945`). Read into a `static final` at `PaxosState` class init, so restart required; no setter.


**Limit type (2026-10-29).** config: yaml entry. The traced constraint decides ([README §6](../../../stage3-ai-deep-read/README.md#6-rules-that-hold-for-both-agents)).
**A2. What it caps.** Heap held by `PaxosState.RECENT`. Operand: Caffeine weighted size = Σ `saturatedCast(accepted.update.unsharedHeapSize() + committed.update.unsharedHeapSize())` (`PaxosState.java:73-74`).

**A3. Mechanism.**
1. Startup check ([`DatabaseDescriptor.java:849-861`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/config/DatabaseDescriptor.java#L849-L861)).
2. `RECENT = Caffeine.newBuilder().maximumWeight(getPaxosCacheSizeInMiB() << 20).weigher(...)` ([`PaxosState.java:72-76`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/service/paxos/PaxosState.java#L72-L76)).
3. A `PaxosState` is taken from `ACTIVE` (or created from `RECENT.remove(key)`) by `getUnsafe`/`tryGetUnsafe`/`lock` (`:355-399`); used by v1 `legacyPrepare`/`legacyPropose` (`:720-723`, `:764-770`) and `commitDirect` (`:672-675`). On `close()`, when the last user leaves, the current `Snapshot` is stashed into `RECENT` (`:513-527`). Caffeine evicts above the maximum weight.
- Bypass/overshoot: `ACTIVE` (`:71`) is an unbounded `ConcurrentHashMap` of partitions with active operations; weight ignores non-update fields; eviction amortised.

**A4. Other consumers.** `system.paxos` table (memtables, SSTables on disk), Paxos v2 uncommitted tracking (`PaxosStateTracker`, `:79-95`), memtables of the user table.

**A5. Evidence beyond the source.** none (no yaml documentation for this key).
