## A. Constraint trace

**A1. The constraint.** `index_summary_capacity`, configuration entry ([`Config.java:539-540`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/config/Config.java#L539-L540), `volatile LongMebibytesBound`, default `null` = auto; legacy `index_summary_capacity_in_mb`), yaml `conf/cassandra.yaml:939` (comment `:931-938`; the comment says "Min unit: KiB" but the type is a MiB-bound spec, so KiB values are refused by [`DataStorageSpec.java:86`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/config/DataStorageSpec.java#L86)). Auto: `max(1, totalMemory*0.05/1MiB)` ([`DatabaseDescriptor.java:866-869`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/config/DatabaseDescriptor.java#L866-L869)). Negative → `ConfigurationException` (`:871-873`), unreachable (`DataStorageSpec.java:42,72,107-108`). Written back `:876`; getter `getIndexSummaryCapacityInMiB()` (`:3886-3889`). Runtime: JMX `IndexSummaryManagerMBean.setMemoryPoolCapacityInMB` ([`IndexSummaryManagerMBean.java:26`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/io/sstable/indexsummary/IndexSummaryManagerMBean.java#L26)), no validation there.


**Limit type (2026-10-29).** config: yaml entry. The traced constraint decides ([README §6](../README.md#6-rules-that-hold-for-both-agents)).
**A2. What it caps.** Off-heap memory of index summaries of SSTable formats with summaries (BIG). Operand: `remainingBytes = memoryPoolBytes − nonRedistributingOffHeapSize` distributed across SSTables by read rate (`IndexSummaryRedistribution.java:138-145`, `:162-229`). Observable total: `getMemoryPoolSizeInMB()` = Σ `getIndexSummary().getOffHeapSize()` (`IndexSummaryManager.java:193-199`).

**A3. Mechanism.**
1. Startup check ([`DatabaseDescriptor.java:866-876`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/config/DatabaseDescriptor.java#L866-L876)).
2. `IndexSummaryManager` constructor sets `memoryPoolBytes = capacity MiB × 2^20` and schedules redistribution every resize interval ([`IndexSummaryManager.java:96-109`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/io/sstable/indexsummary/IndexSummaryManager.java#L96-L109), `:116-145`).
3. `redistributeSummaries()` (`:239-252`) builds an `IndexSummaryRedistribution` with the pool size; `adjustSamplingLevels` gives each SSTable `idealSpace = remainingSpace × readsPerSec/totalReadsPerSec` ([`IndexSummaryRedistribution.java:183`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/io/sstable/indexsummary/IndexSummaryRedistribution.java#L183)) and downsamples, clamped so the effective interval never exceeds `max_index_interval` (`:224-229`).
- Overshoot: between runs, new/compacted SSTables get full-resolution summaries (`min_index_interval`, default 128, [`TableParams.java:364-365`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/schema/TableParams.java#L364-L365)); clamping at `max_index_interval` (default 2048) means the total can stay above the pool; redistribution is skipped while global compaction is paused ([`IndexSummaryManager.java:241-242`](https://github.com/apache/cassandra/blob/cassandra-5.0.9/src/java/org/apache/cassandra/io/sstable/indexsummary/IndexSummaryManager.java#L241-L242)); `index_summary_resize_interval` null disables it (yaml `:941-947`).

**A4. Other consumers.** Bloom filters and compression metadata (off-heap, per SSTable), BTI partition index (on disk, mmapped), chunk cache, memtable off-heap, key cache.

**A5. Evidence beyond the source.** `conf/cassandra.yaml:931-947` (explicitly "best-effort … may need to use more than this amount of memory").

Leftover space can cancel downsamples (`:258-265, 327-356`). An upsample rebuilds from the primary index at the new level, so level 128 has exactly maxEntries entries (`BigTableReader.java:600-604, 625-640`, `IndexSummaryBuilder.java:273`). A downsample copies from the existing summary (`IndexSummaryBuilder.java:324-379`).
