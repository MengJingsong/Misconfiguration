# Harness — internode_max_message_size-enqueue-getInternodeMaxMessageSizeInBytes--autonomous

Stage-4 harness for the autonomous case file (frozen sha256 `9edf2196…`, see the results file
[§1](../../results/internode_max_message_size-enqueue-getInternodeMaxMessageSizeInBytes--autonomous.md)). Written
2026-10-20 after the step-0 audit and the freeze. Run on `pc12` (`node1.jason92-320876`) from
`~/stage4-harness-run/ime/` against the clone `~/cassandra-run1` (`cassandra-5.0.9`, `b5f2a54210`, `ant build-test`).
Logs go to `~/stage4-logs/ime/<run>/` on the node; node data under `/mydata/stage4-ime/` (local disk), deleted after
every lifetime. The two nodes of the cluster tier run on this one host on loopback (environment deviation: the audit
assumed `pc57` + `pc50`, no longer in the experiment).

| `MaxMessageSizeProbeTest.java` | unit (B2) | Package `org.apache.cassandra.net`; copied into the clone's `test/unit/org/apache/cassandra/net/` by `unit-run.sh` and removed after.
