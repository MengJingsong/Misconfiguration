# U4 — stage 3-a JIRA check (2026-11-24)

**Case:** [`cql-row-limit--wide-row-default-pages`](../cases/cql-row-limit--wide-row-default-pages/cql-row-limit--wide-row-default-pages.md)
(true positive, `verified-OOM · deployment`).

**Mechanism checked (§4).** A page is bounded only in rows (`DataLimits` `rowsCounted`; the drivers' default 5,000), the byte bound
(`read_thresholds_enabled`, `local_read_size_*`) ships off, and nothing sums bytes across concurrent reads; each in-flight page of
5,000 × 48 KiB rows holds a 216–324 MiB replica `DataOutputBuffer` (plus the coordinator `ResultSet`) on the heap, so three
concurrent paged reads OOM a 2 GiB heap.

**Label: `known-fixed (not in 5.0.9)` (exact: CASSANDRA-11745, fix 6.0-alpha3, opt-in; CASSANDRA-11528 also open)**

**Owner ruling (2026-11-24):** an opt-in fix counts as known-fixed. CASSANDRA-11745 describes U4 exactly and its 6.0-alpha3 fix adds opt-in byte paging (not in 5.0.9), so the label is `known-fixed (not in 5.0.9)`.

**Label (stage 3-a as first filed): `known-open` (exact: CASSANDRA-11528, Open; partial: CASSANDRA-6492, Open)** — CASSANDRA-11745's comment of 2025-10-28
also describes U4 exactly, and 11745 is Resolved/Fixed in 6.0-alpha3 (not in 5.0.9), but its fix is **opt-in** byte paging
(client byte fetch size over protocol v5+); explicit row pages, including every driver default, are unchanged and the
hard page cutoff that comment asked for was not adopted. So the fix does not cover U4 at defaults, in 5.0.9 or in 6.0, and it is
not counted as known-fixed. **For the owner:** if a resolved issue whose fix adds only an opt-in control should count, the label
would be `known-fixed (not in 5.0.9) (exact: CASSANDRA-11745)`.

## Reason

Stage 1 rated the row limit `by design` (4304, 4743, 5336) and noted 11745's comment. Under 3-a's match rules the open
CASSANDRA-11528 reports U4's OOM with a committer's root cause (5,000-row driver pages × multi-MB rows held in memory), so U4 is
mentioned (exact) and still open; 6492 (open) asks for the server-side default that would bound it, and 9413 (Won't Fix) names the
missing cross-request bound. 11745 is the only resolved issue on point; its 6.0 fix adds opt-in byte pages and leaves default
row paging as it was (Har'El's requested cutoff not done), so U4's mechanism remains at defaults after it — not an incidental fix.
Hence `known-open (exact: CASSANDRA-11528)`, with the alternative reading flagged above.
