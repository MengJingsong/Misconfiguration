# R22 — stage 3 JIRA check (2026-11-23)

**Case file:** [`../cases/range-tombstone-list--forced-thrash-queues-large-local-writes/range-tombstone-list--forced-thrash-queues-large-local-writes.md`](../cases/range-tombstone-list--forced-thrash-queues-large-local-writes/range-tombstone-list--forced-thrash-queues-large-local-writes.md)
(verdict true positive; `verified-OOM · deployment`, unprotected accumulation × unprotected accumulation).

**Mechanism checked (case §4).** One hot memtable partition with ≈ 1.2 M range tombstones: each of the 32 MutationStage
writers copies the partition's `RangeTombstoneList` per optimistic attempt (O(n), charged to no counter), so the whole stage
completes only a few writes/s. Every other local write queues in the unbounded MutationStage SEP queue; a write that times
out at 2 s frees its request thread and in-flight bytes but stays queued (and is re-submitted as a hint runnable,
`checkHintOverload` exempting self) → 12 MiB local writes accumulate to a Java heap OOM at 15,872 MiB.

**Label: `known-open (partial: CASSANDRA-13235)`** — changes stage 1's `new`.

**Documented:** no. `conf/cassandra.yaml` documents `concurrent_writes`, `write_request_timeout` and hints but nothing on
range-tombstone write cost per partition or on queued local writes surviving their timeout; nothing in `doc/`, `NEWS.txt`.

**Reason.** Stage 1 (2026-11-21) listed 13235 as a generic "all threads blocked" stall. Reading it in full, its only
diagnostic is a jstack showing exactly R22's stall: all MutationStage threads contending on one partition while one copies
its `RangeTombstoneList`, with thousands of writes pending. That reports R22's trigger and the queued-write backlog, but
not the memory holder or the OOM and no root cause, so it is **partial**; it is Open → **known-open**. The copy cost itself
is known-open in 21492 (related: single-writer cost, no stall or backlog), the unbounded queue is by design (5039, 11460
Won't Fix), and the backlog → OOM with other stall sources is open (13213). No issue joins them into "one range-tombstone
hot partition at defaults stalls every local write until the heap is gone"; R22 is the first OOM evidence for 13235.
